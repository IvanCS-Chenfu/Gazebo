# Gazebo

Repositorio de apoyo de la Wiki de **Gazebo Classic 11 + ROS 2 Iron**.

La documentación actual se mantiene en la [Wiki del repositorio](https://github.com/IvanCS-Chenfu/Gazebo/wiki).

## Histórico

El código, modelos, configuraciones y páginas de la etapa anterior se conservan íntegramente en [`legacy/`](./legacy/). Ese contenido se mantiene como **referencia histórica** y no debe interpretarse automáticamente como la implementación o documentación canónica actual.

La reconstrucción actual desarrolla primero la teoría. Los nuevos ejemplos de código, imágenes, vídeos y experimentos se incorporarán posteriormente de forma progresiva y validada.
